# 오늘의스터디 랜딩페이지 디자인 명세

## 목표

첨부된 레퍼런스의 정보 구조, 문구 체계, 흑백과 라임색의 시각 언어, 제품 목업 중심의 레이아웃을 반응형 웹페이지로 재현한다. 페이지의 핵심 전환은 방문자가 서비스의 가치를 빠르게 이해하고 `무료로 시작하기` 버튼을 누르는 것이다.

## 구현 범위

- 단일 랜딩페이지(`/`)만 구현한다.
- 상단 내비게이션의 메뉴는 페이지 내 해당 섹션으로 스크롤한다.
- `무료로 시작하기`, `로그인`, `도입 문의하기` 버튼은 실제 연결 주소가 정해지기 전까지 안전한 페이지 내 앵커로 동작한다.
- 별도의 회원가입, 결제, 관리자 기능, 데이터베이스 연동은 포함하지 않는다.
- 데스크톱과 모바일 화면을 모두 지원한다.

## 시각 방향

- 배경은 흰색과 짙은 검정 섹션을 교차해 긴 페이지의 리듬을 만든다.
- 강조색은 밝은 라임색 하나로 제한하고 제목 키워드, 작은 영문 라벨, 주요 CTA에 사용한다.
- 제목은 굵고 밀도 높은 산세리프체, 본문은 읽기 편한 중간 굵기의 한글 산세리프체를 사용한다.
- 카드와 목업은 얇은 테두리, 부드러운 그림자, 16~28px의 둥근 모서리를 사용한다.
- 장식용 모델 작성 SVG는 사용하지 않는다. 단순 아이콘은 CSS 또는 기존 아이콘 구성으로 만들고, 기기 및 제품 화면은 HTML/CSS 목업으로 재구성한다.

## 페이지 구조

### 1. 상단 내비게이션

- 좌측: 오늘의스터디 워드마크
- 중앙: 서비스 소개, 기능, 요금제, 도입사례
- 우측: 로그인, 무료로 시작하기
- 데스크톱에서는 한 줄 고정 폭 컨테이너, 모바일에서는 로고와 메뉴 버튼만 노출한다.

### 2. 메인 히어로

- 좌측: 서비스 성격을 설명하는 짧은 문장, 대형 헤드라인, 보조 문구, 기본/보조 CTA
- 핵심 헤드라인: `학생의 오늘을 기록하고, 내일의 성장을 만듭니다.`
- `성장`을 라임색으로 강조한다.
- 우측: 기울어진 태블릿, 휴대폰, 펜이 겹치는 제품 목업
- 화면 하단 중앙에 스크롤 안내를 둔다.

### 3. 핵심 강점

- 검정 배경 위에 `학원을 가장 잘 아는 사람들이 만들었습니다` 메시지를 배치한다.
- 현장 중심 설계, 데이터 성장, 소통의 연결, 안전한 보안의 네 항목을 동일 너비로 나눈다.
- 각 항목은 단색 아이콘, 제목, 두 줄 설명으로 구성한다.

### 4. 출석 체크 기능

- 흰 배경의 2열 구성이다.
- 좌측은 `태블릿으로 끝내는 출석 체크와 자동 알림` 제목, 설명, 체크 목록을 제공한다.
- 우측은 출석 관리 대시보드 목업을 크게 배치해 실제 제품 화면처럼 보이게 한다.

### 5. 학원 업무 흐름

- 연한 회색 배경에서 수업 전, 등원, 수업 중, 수업 분석, 학부모 소통의 다섯 단계를 가로 탭처럼 보여준다.
- 첫 번째 단계인 수업 준비를 기본 활성 상태로 둔다.
- 좌측 체크리스트 카드, 중앙 태블릿 목업, 우측 단계 설명과 `다음 단계 보기` 버튼을 배치한다.
- 구현 초기에는 탭을 클릭하면 설명과 활성 표시가 바뀌는 가벼운 상호작용만 제공한다.

### 6. 주요 관리 기능

- 검정 배경 위에 `직관적인 화면 강력한 기능` 메시지를 배치한다.
- 중앙에는 넓은 관리자 대시보드 목업을 두고, 좌우에 기능 설명 콜아웃을 연결한다.
- 콜아웃은 출결 관리와 빠른 확인처럼 핵심 기능을 짧게 설명한다.

### 7. 고객 후기와 지표

- 좌측에는 만족도, 평균 평점, 누적 고객 수를 큰 숫자로 표시한다.
- 우측에는 인물 사진이 포함된 후기 카드 세 장을 겹치지 않게 나열한다.
- 인물 사진은 레퍼런스와 유사한 밝은 교육·사무 환경의 이미지를 사용하되, 실제 고객으로 오해하지 않도록 이름과 직함은 예시임을 명확히 한다.

### 8. 요금제

- 연한 회색 배경의 2열 구성이다.
- 좌측은 `공부 관리, 이제는 시스템의 차이` 헤드라인과 이용 정책 요약을 배치한다.
- 우측은 Premium을 큰 대표 카드로, Starter와 Enterprise를 세로로 쌓는다.
- 가격, 포함 기능, CTA, 추천 배지를 레퍼런스와 같은 우선순위로 표현한다.

### 9. 최종 CTA와 푸터

- 검정 배경 CTA에서 `지금 시작하면, 학원의 내일이 달라집니다.`를 크게 노출하고 무료 시작/도입 문의 버튼을 제공한다.
- 배경에는 라임색 곡면과 가는 선 패턴을 CSS 장식으로 구성한다.
- 푸터에는 로고, 서비스 설명, 사업자 정보, 저작권, 문의 전화와 이메일을 배치한다.

## 컴포넌트 경계

- `Header`: 내비게이션과 모바일 메뉴
- `HeroSection`: 핵심 메시지와 기기 목업
- `BenefitsSection`: 네 가지 서비스 강점
- `AttendanceSection`: 출석 기능 설명과 대시보드
- `ClassFlowSection`: 단계 탭과 단계별 콘텐츠
- `FeatureShowcaseSection`: 관리자 화면과 콜아웃
- `TestimonialsSection`: 지표와 후기 카드
- `PricingSection`: 요금제 비교 카드
- `FinalCtaSection`: 마지막 전환 영역
- `Footer`: 회사 및 문의 정보
- `DeviceMockup`, `DashboardMockup`, `SectionLabel`, `PrimaryButton`은 반복 사용 가능한 표현 컴포넌트로 분리한다.

## 상태와 데이터 흐름

- 페이지 콘텐츠와 요금제는 정적 데이터 객체로 관리해 마크업과 문구를 분리한다.
- 유일한 화면 상태는 모바일 메뉴 열림 여부와 학원 업무 흐름의 활성 단계다.
- 외부 API 호출이나 영속 데이터는 없다.
- 자바스크립트가 꺼진 경우에도 첫 번째 업무 단계와 모든 핵심 콘텐츠를 읽을 수 있어야 한다.

## 반응형 규칙

- 데스크톱: 최대 콘텐츠 폭 약 1200px, 주요 섹션은 2열 또는 4열 구성
- 태블릿: 목업 크기를 축소하고 4열 항목은 2열로 변경
- 모바일: 모든 주요 섹션을 한 열로 배치하고, 텍스트를 목업보다 먼저 표시
- 모바일 헤드라인은 40px 안팎, 데스크톱은 64px 안팎으로 조절한다.
- 버튼은 모바일에서 충분한 터치 영역을 확보하고 필요한 경우 전체 너비로 확장한다.

## 접근성과 실패 처리

- 모든 버튼과 메뉴는 키보드로 접근할 수 있고 명확한 포커스 표시를 제공한다.
- 장식 이미지는 빈 대체 텍스트를, 의미 있는 이미지는 목적을 설명하는 대체 텍스트를 사용한다.
- 색상만으로 활성 상태를 전달하지 않고 밑줄, 테두리, 굵기를 함께 사용한다.
- 별도 원본 이미지가 없거나 이미지 로딩이 실패해도 레이아웃이 유지되도록 목업과 배경색을 기본 표현으로 제공한다.
- 외부 연결 주소가 확정되지 않은 CTA는 잘못된 외부 이동 대신 페이지 내 문의/요금제 섹션으로 연결한다.

## 검증 기준

- 프로덕션 빌드가 오류 없이 완료된다.
- 1440px 화면에서 레퍼런스의 섹션 순서, 폭, 밝고 어두운 배경 리듬이 유지된다.
- 768px과 390px에서 가로 스크롤 없이 모든 텍스트와 CTA를 사용할 수 있다.
- 내비게이션 앵커, 모바일 메뉴, 업무 흐름 탭이 키보드와 터치로 동작한다.
- 제목 계층, 링크 이름, 버튼 레이블, 이미지 대체 텍스트를 점검한다.

## 완료 조건

- 스타터 화면과 임시 메타데이터가 오늘의스터디 랜딩페이지로 완전히 교체된다.
- 아홉 개 섹션이 모두 구현되고 레퍼런스와 같은 정보 우선순위를 가진다.
- 데스크톱과 모바일에서 시각적으로 안정적이며 빌드 검증을 통과한다.
- 실제 서비스 주소가 없는 CTA의 임시 동작이 코드와 문서에서 명확하다.
